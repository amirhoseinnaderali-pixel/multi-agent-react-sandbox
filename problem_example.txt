Problem: Calculate factorial of a number

Write a Python function that calculates the factorial of a non-negative integer n.

Requirements:
1. The function should be named `factorial`
2. It should take one parameter: n (an integer)
3. It should return the factorial of n
4. Handle edge cases: factorial(0) = 1
5. The program should read input from stdin and print the result

Example:
Input: 5
Output: 120

Input: 0
Output: 1

Input: 10
Output: 3628800
